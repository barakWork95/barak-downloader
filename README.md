# Barak ⚡ Downloader

אפליקציה למק להורדת סרטונים מיוטיוב, אינסטגרם, טיקטוק, פייסבוק, X ועוד מאות אתרים (כל מה ש-yt-dlp תומך בו). בוחרים איכות, חותכים קטע, מכינים קובץ קטן לוואטסאפ.

**להורדה ולהוראות התקנה: https://barakwork95.github.io/barak-downloader/**

macOS 14 ומעלה, Apple Silicon ו-Intel. חינם, קוד פתוח (MIT).

## מה יש

- **בחירת איכות** עם הגודל האמיתי של כל אפשרות. ברירת המחדל היא האיכות הכי גבוהה ב-H.264 (בדרך כלל 1080p), שנפתחת בכל נגן.
- **חיתוך קטע:** מורידים רק את הטווח שבוחרים. קישור עם `?t=90` פותח את החיתוך מאותה שנייה.
- **קובץ קטן לוואטסאפ:** H.264 עד 720p, מכווץ לבערך 15MB ומתנגן בכל טלפון.
- **תור והיסטוריה**, התראות כשהורדה מסתיימת, ופס התקדמות על האייקון ב-Dock.
- **MP3 עם עטיפה ופרטי היוצר.**
- **תוסף לכרום** (`chrome-extension/`) ששולח סרטון לאפליקציה דרך `barak://add?url=...`.
- **אייקון בסרגל התפריטים** (לא חובה), שמציע להוריד קישור שהעתקת.
- **הגדרות:** תיקיית שמירה, תיקייה לכל פלטפורמה, סגנון שם הקובץ, דילוג על קטעי חסות ביוטיוב (SponsorBlock).

## איך זה בנוי

**האפליקציה קטנה, והכלים יורדים בפתיחה הראשונה.** אם הכלים היו ארוזים בפנים לשני סוגי המעבדים, ה-DMG היה בערך 400MB. לכן בפתיחה הראשונה האפליקציה מורידה רק את מה שמתאים למעבד של המשתמש (בערך 135MB), בודקת SHA-256, ומתקינה תחת `~/Library/Application Support/Barak Downloader/tools/`:

- **yt-dlp:** מה-Releases הרשמיים, הגרסה שאורזת את כל מה שהוא צריך (`yt-dlp_macos.zip`). מתעדכן לבד פעם ביום, כי האתרים משתנים כל הזמן.
- **Deno:** מה-Releases הרשמיים. yt-dlp צריך אותו כדי להתמודד עם ההגנות של יוטיוב. בדקנו גם את QuickJS: הוא קטן פי 30, אבל קריאת סרטון ביוטיוב לקחה איתו 11.6 שניות במקום 2.6.
- **FFmpeg:** נבנה כאן מהקוד הרשמי, ברישיון LGPL (בלי x264). קידוד הוידאו, בחיתוך ובוואטסאפ, נעשה ב-VideoToolbox של אפל. ה-TLS הוא של המערכת (SecureTransport). הסקריפט: [`scripts/build-ffmpeg.sh`](scripts/build-ffmpeg.sh). ה-workflow `Build FFmpeg` מפרסם את התוצאה ב-Release בשם `tools-ffmpeg-<גרסה>`.

**הגרסאות וקודי האימות קבועים בקוד** ([`app/Tools.swift`](app/Tools.swift)). אין הורדה של קבצים מאתרים פרטיים.

| קובץ | תפקיד |
|---|---|
| `app/EngineCore.swift` | המנוע: קריאת הסרטון, בחירת פורמטים מדויקים (כדי שהגודל שמוצג יהיה האמיתי), הורדה עם התקדמות, חיתוך, כיווץ לוואטסאפ, סיווג שגיאות. |
| `app/Tools.swift` | הורדה, אימות, התקנה ועדכון של הכלים, ומסך ההכנה בפתיחה הראשונה. |
| `app/Prepare.swift` | שלב ההכנה (קישור ← איכות/חיתוך/וואטסאפ ← תור), גישה ללוח, ופתיחת קישורים מבחוץ. |
| `app/Jobs.swift` | תור ההורדות, ההיסטוריה, ה-Dock וההתראות. |
| `app/Views.swift`, `app/Settings.swift` | המסכים, החלונית בסרגל התפריטים וההגדרות. |
| `app/Updates.swift` | בדיקה פעם ביום אם יצאה גרסה חדשה (GitHub Releases). |
| `app/AppMain.swift` | הפעלת האפליקציה, קישורי `barak://`, ומצבי הבדיקה. |
| `tools/make_icon.swift` | מצייר את האייקון. הברק מקורי, בלי אימוג'י ובלי SF Symbols, ששניהם אסורים באייקון של אפליקציה. |
| `build.sh` | בונה Universal (arm64 + x86_64). `--install` גם מעתיק לשולחן העבודה. `ICON=electric` בוחר את גרסת האייקון הכהה. |
| `engine.py`, `ytdl.py` | גרסת הטרמינל (`ytdl` / `barak`), שעובדת עם yt-dlp ו-ffmpeg של Homebrew. לא חלק מהאפליקציה. |
| `docs/` | דף הנחיתה (GitHub Pages). |

## פרסום גרסה

1. מעדכנים את `CFBundleShortVersionString` ב-`app/Info.plist`, למשל `1.1.0`.
2. מריצים:

```bash
git tag v1.1.0 && git push --tags
```

ה-workflow `Release` בונה את האפליקציה, אורז `Barak-Downloader.dmg` ו-`Barak-Chrome-Extension.zip`, ומפרסם Release. דף הנחיתה מצביע תמיד ל-`releases/latest`. האפליקציות שכבר מותקנות יראו הודעה על הגרסה החדשה.

**עדכון הכלים:**
- **FFmpeg:** מריצים את `Build FFmpeg` (workflow_dispatch) ומעדכנים גרסה וקודי אימות ב-`app/Tools.swift`.
- **yt-dlp ו-Deno:** מעדכנים גרסה וקוד אימות מהקבצים הרשמיים. yt-dlp ממילא מתעדכן לבד אצל המשתמשים.

**חתימה:** האפליקציה חתומה ad-hoc בלבד, בלי חשבון Apple Developer. לכן בפתיחה הראשונה צריך "פתח בכל זאת" בהגדרות הפרטיות. ההסבר נמצא בדף הנחיתה. כשיהיה חשבון, מוסיפים לתהליך הבנייה חתימה עם Developer ID ונוטריזציה.

## החלטות

- **האפליקציה בוחרת בעצמה את מספרי הפורמטים ומעבירה אותם ל-yt-dlp**, ולכן הגודל שמוצג הוא הגודל שמתקבל.
- **ההורדה נעשית בתיקייה זמנית** (`-P temp:`), ולכן ביטול לא משאיר קבצים חלקיים.
- **חיתוך מדויק מקודד את הקטע מחדש.** זה נעשה עם `--downloader-args "ffmpeg_o:-c:v h264_videotoolbox ..."`, כי ב-FFmpeg ברישיון LGPL אין x264.
- **הלוח:** ב-macOS 15.4 ומעלה, אפליקציה שקוראת את הלוח בעצמה מקפיצה בקשת הרשאה. לכן:
  - האפליקציה רק בודקת אם יש בלוח קישור (`detectedPatterns`), בלי לקרוא את התוכן.
  - היא קוראת אותו רק אם המשתמש נתן "אפשר תמיד".
  - הכפתור "הדבק" מבצע הדבקה אמיתית לשדה (`paste:`), שלא דורשת הרשאה.
- **הסצנות של SwiftUI לא צופות במודלים שמשתנים כל הזמן.** שינוי כזה בזמן ההפעלה נכנס ללולאה אין-סופית שהפילה את האפליקציה.
- **השם:** עד 2026-11-24 האפליקציה נקראה "מוריד סרטונים" (`local.claude.video-downloader`). ההגדרות וההיסטוריה עוברות לבד. תוסף הכרום ממשיך לחיות בתיקייה הישנה אם הותקן משם.

## בדיקות

```bash
APP="build/Barak Downloader.app/Contents/MacOS/Barak"
SNAPSHOT_SCALE=2 "$APP" --snapshot <תיקייה>    # צילום של כל מסך, בהיר וכהה
# מק נקי: בלי Homebrew, תיקיית תמיכה ריקה; הכלים יורדים מהאינטרנט
env -i HOME="$HOME" BARAK_SUPPORT_DIR=<תיקייה-ריקה> YTDL_DIR=<תיקיית-הורדות> "$APP" --selftest <קישור> <מספר-איכות> [whatsapp] [trim=0:30-0:42] [cancel] [queue2]
# בפיתוח, עם הכלים של Homebrew:
BARAK_SYSTEM_TOOLS=1 "$APP" --selftest ...
open "barak://add?url=https%3A%2F%2Fyoutu.be%2F..."   # כמו התוסף
```
