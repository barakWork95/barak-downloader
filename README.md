# Barak ⚡ Downloader

הורדת סרטונים מיוטיוב, אינסטגרם, טיקטוק, פייסבוק, X ועוד מאות אתרים (כל מה ש-yt-dlp תומך בו), עם בחירת איכות. הקבצים נשמרים בתיקיית ההורדות, או בתיקייה שבוחרים בהגדרות.

## דרכים להשתמש

- **אפליקציה:** `Barak Downloader.app` בשולחן העבודה. מדביקים קישור (או גוררים אותו לחלון), בוחרים איכות, וההורדה נכנסת לרשימה.
- **תוסף כרום:** כפתור בסרגל של כרום, או קליק ימני על קישור או סרטון, שולח אותו לאפליקציה. התקנה: הגדרות ← "הצג את התוסף ב-Finder", ואז גוררים את התיקייה לדף `chrome://extensions` כש"מצב מפתח" (Developer mode) פעיל.
- **סרגל התפריטים** (מופעל בהגדרות): אייקון ליד השעון שמראה את ההורדות, והאפליקציה ממשיכה לפעול גם כשהחלון סגור.
- **טרמינל:** `barak` (או `ytdl`), אפשר גם `barak <קישור>`.

## השם
עד 2026-11-24 האפליקציה נקראה "מוריד סרטונים", עם המזהה `local.claude.video-downloader` והסכמה `videodownloader://`.
- **ההגדרות וההיסטוריה עוברות אוטומטית** בהפעלה הראשונה.
- **תוסף הכרום ממשיך לחיות בתיקייה הישנה** (`Application Support/VideoDownloader/chrome-extension`) אם הותקן משם, כדי שההתקנה בכרום לא תישבר. האפליקציה מרעננת את הקבצים שלו בכל הפעלה.

## מה יש

- **בחירת איכות** עם הגודל האמיתי של כל אפשרות. ברירת המחדל היא האיכות הכי גבוהה ב-H.264 (בדרך כלל 1080p), שנפתחת בכל נגן.
- **חיתוך קטע:** מורידים רק את הטווח שבוחרים. קישור עם `?t=90` פותח את החיתוך מאותה שנייה.
- **קובץ קטן לוואטסאפ:** H.264 עד 720p, מכווץ לבערך 15MB ומתנגן בכל טלפון.
- **תור והיסטוריה:** הורדה אחת בכל פעם, השאר ממתינות. ההיסטוריה נשמרת ב-`~/Library/Application Support/Barak Downloader/history.json`, עם "פתח", "הצג ב-Finder", "נסה שוב" ו"הורד שוב".
- **התראה כשהורדה מסתיימת** (כשהאפליקציה ברקע), ופס התקדמות על האייקון ב-Dock.
- **MP3 עם עטיפה ופרטי האמן**, ופרטי הסרטון בתוך קבצי MP4.
- **הגדרות** (⌘,): תיקיית שמירה, תיקייה נפרדת לכל פלטפורמה, סגנון שם הקובץ, דילוג על קטעי חסות ביוטיוב (SponsorBlock, כבוי כברירת מחדל), התראות וסרגל התפריטים.

## מבנה

| קובץ | תפקיד |
|---|---|
| `engine.py` | כל הלוגיקה: קריאת הסרטון, בחירת הפורמטים, הורדה עם התקדמות, חיתוך, כיווץ לוואטסאפ, סיווג שגיאות. גם מודול וגם פקודת JSON בשביל האפליקציה. |
| `ytdl.py` | ממשק הטרמינל (קיצורים ב-`~/.local/bin/barak` וב-`~/.local/bin/ytdl`). |
| `app/Engine.swift` | הרצת המנוע, המודלים, ופונקציות עזר לזמן וגודל. |
| `app/Prepare.swift` | שלב ההכנה (קישור ← איכות/חיתוך/וואטסאפ ← תור), גישה ללוח, ופתיחת קישורים מבחוץ. |
| `app/Jobs.swift` | תור ההורדות, ההיסטוריה, ה-Dock וההתראות. |
| `app/Views.swift` | המסכים והחלונית של סרגל התפריטים. |
| `app/Settings.swift` | ההגדרות ומסך ההגדרות. |
| `app/AppMain.swift` | הפעלת האפליקציה, קישורי `barak://`, ומצבי הבדיקה. |
| `chrome-extension/` | תוסף הכרום (MV3). |
| `tools/make_icon.swift` | מצייר את האייקון: ברק מקורי (בלי אימוג'י ובלי SF Symbols, שאסורים באייקון). |
| `build.sh` | בונה את האפליקציה. `./build.sh --install` גם מעתיק אותה לשולחן העבודה. `ICON=electric` בוחר את גרסת האייקון הכהה (ברירת המחדל: brand). |

**אחרי כל שינוי ב-`engine.py` או בתוסף צריך להריץ `./build.sh --install`**, כי באפליקציה יש עותק משלה של שניהם.

## החלטות

- **הסקריפט בוחר בעצמו את מספרי הפורמטים ומעביר אותם ל-yt-dlp**, ולכן הגודל שמוצג הוא הגודל שמתקבל.
- **ההורדה נעשית בתיקייה זמנית** (`-P temp:`), ולכן ביטול לא משאיר קבצים חלקיים. גם הכיווץ לוואטסאפ נכתב לקובץ זמני ומועבר רק בסוף.
- **הלוח:** ב-macOS 15.4 ומעלה, אפליקציה שקוראת את הלוח בעצמה מקפיצה בקשת הרשאה. לכן:
  - האפליקציה רק בודקת אם יש בלוח קישור (`detectedPatterns`), בלי לקרוא את התוכן.
  - היא קוראת אותו רק אם המשתמש נתן "אפשר תמיד".
  - הכפתור "הדבק" מבצע הדבקה אמיתית לשדה (`paste:`), שלא דורשת הרשאה.
- **תוסף הכרום שולח `barak://add?url=...`.** בפעם הראשונה כרום שואל אם לפתוח את האפליקציה.
- **כשסרטון דורש התחברות**, יש כפתור שמנסה דרך העוגיות של כרום (`--cookies-from-browser chrome`). המק יבקש אישור גישה ל-Keychain.

## בדיקות

```bash
APP="build/Barak Downloader.app/Contents/MacOS/Barak"
"$APP" --snapshot <תיקייה>     # צילום של כל מסך, בהיר וכהה, וגם ההגדרות וסרגל התפריטים
YTDL_DIR=<תיקייה> "$APP" --selftest <קישור> <מספר-איכות> [whatsapp] [trim=0:30-0:42] [cancel] [queue2]
open "barak://add?url=https%3A%2F%2Fyoutu.be%2F..."   # כמו התוסף
```

## כשמשהו מפסיק לעבוד

האתרים משנים דברים כל הזמן. בדרך כלל זה נפתר עם `brew upgrade yt-dlp`, או עם הכפתור "עדכן את yt-dlp" במסך השגיאה.
